# 🛣️ Расчёт остаточного ресурса дорожных конструкций

Веб-приложение для оценки остаточного ресурса нежёстких дорожных одежд
в соответствии с **СТО АВТОДОР 2.4-2013** и **СТО АВТОДОР 2.28-2016**.

---

## Что делает программа

1. **Рассчитывает суммарное число приложений расчётной нагрузки `ΣNp`**
   по данным об интенсивности и составе транспортного потока.

2. **Оценивает остаточный ресурс `ΣNост`** двумя методами:
   - **По нагрузке** — через накопленное число приложений.
   - **По прочности** — через фактический коэффициент прочности `Kпр`.

3. **Прогнозирует продольную ровность IRI** по годам эксплуатации.

4. **Даёт рекомендации** по планированию ремонтных работ.

## Что вводить

### Боковая панель (общие настройки)

- **Категория автомобильной дороги** — IА, IБ, IВ, II, III, IV, V.
- **Расчётная нагрузка** — 100 или 115 кН.
- **Расчётный срок службы** — обычно 18 лет.
- **Количество полос движения**.
- **Годовой прирост интенсивности** — например, 5%.
- **Расчётное число дней в году `Трдг`** — обычно 205.
- **Текущий IRI** — на момент диагностики.
- **Фактический срок эксплуатации** — сколько лет уже работает дорога.
- **Тип дорожной одежды** — Капитальный / Облегчённый / Переходный.
- **Kпр_тр** — подставляется автоматически по ГОСТ Р 71404.
- **Kпр_факт** — фактический коэффициент прочности из диагностики.
- **Критический порог IRI** — по ГОСТ Р 50597-2017 или вручную.

### Вкладки

- **📊 Интенсивность** — ввод интенсивности по классификациям СТО или ГОСТ.
- **🚗 Типы ТС** — справочник и редактирование масс.
- **🔮 Прогноз IRI** — прогноз продольной ровности.
- **🧮 Расчёт** — параметры расчёта и кнопка «Рассчитать».
- **📈 Результаты** — метрики, графики, оценка прочности.

---

## Как читать результаты

- **ΣNp (проект)** — сколько приложений нагрузки заложено при проектировании.
- **ΣNp (факт)** — сколько накоплено на текущий момент.
- **ΣNост** — остаточный ресурс (в млн. авт. и в %).
- **Kпр_факт** vs **Kпр_тр** — оценка прочности.
- **График накопления** — проектная кривая vs фактическая.
- **Прогноз IRI** — как будет меняться ровность по годам.

---

## Ограничения

- Оценка **остаточного ресурса по прочности** через масштабирование кривой
СТО 2.4-2013 (рисунок 8.1) — **ориентировочная**. Нормативная методика
перехода от `Kпр` к остаточному ресурсу в настоящее время **отсутствует**.
- Программа не заменяет **проектную документацию** и **специализированное
обследование**, а служит инструментом для предварительной оценки и
планирования.
